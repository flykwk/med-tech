## The problem

Radiation devices share users, workflows and safety requirements, but their interfaces had grown separately. [Describe what you saw: inconsistent patterns, duplicated work, slow design-to-development handoff, difficulty maintaining products over time.]

In a clinical setting, inconsistency is more than a visual issue. Clinicians who move between devices need familiar patterns so they can work quickly and with confidence.

## My role

I created the design system to provide:

- **Consistency:** the same problem gets the same solution across every device
- **Sustainability:** shared foundations that can be maintained and extended without redesigning each product
- **Scalability:** a constrained set of reusable decisions that new devices and features can build on

## What's inside

The foundation rules cover:

| Foundation | What it defines |
|---|---|
| **Principles** | How design decisions are made and settled |
| **Design tokens** | Primitive, semantic and component tiers with a naming convention |
| **Color** | Brand, neutral and feedback palettes with accessible contrast pairings |
| **Typography** | Typefaces, type scale, line height and weights |
| **Spacing and layout** | Spacing scale, grid and breakpoints, touch targets |
| **Elevation and shape** | Shadow levels, radii and borders |
| **Iconography** | Style, sizing and accessibility rules |
| **Motion** | Durations, easing and reduced-motion support |
| **Accessibility** | WCAG 2.2 AA targets, keyboard, focus and content rules |
| **Content and voice** | Tone, UI text conventions and formats |
| **Governance** | Contribution, review, versioning and deprecation |
